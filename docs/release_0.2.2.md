# AeroSlice Converter 0.2.2

桌面工作流优化：先“开始转换所选对象”，再“一键转换并导出”时复用已完成的转换结果，仅写文件并回读检查。直接导入后导出仍自动完成转换。再次导出也可复用。

复用依据包含输入顶点和三角面、零件顺序/分组/类型、转换勾选以及全部转换参数。改变壁厚、层高、重建方式、精度或输入几何会重新转换；切换预览显示、更改输出目录、STL/3MF格式或分件导出不触发转换。只允许复用通过几何检查的结果，结果对应任务启动时的参数快照。

GUI模型直接写入所选目录，不生成run时间戳子目录。默认STL，文件名沿用输入名加_converted；同名自动加_2、_3，源文件及已有成品不会覆盖。GUI单件/分件/批量导出不写JSON旁文件，检查及错误信息在窗口查看；开发自检报告和CLI报告仍保留。

未修改曲面重建算法或切片约束。逐层成品仍须保持原Z方向、相同固定层高及Even-Odd；软件帮助中可查看完整设置。未追加实物打印测试。

本次验证覆盖缓存复用/失效、导出格式及目录切换、写入失败、文件碰撞、源文件与缓存几何未变、无JSON旁文件。最终GUI EXE用真实ICON主翼执行导入→转换→右侧导出→顶部再次导出，记录后台任务次数与导出回读结果。实际结果及二进制校验值随test_evidence交付。
