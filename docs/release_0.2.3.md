# AeroSlice Converter 0.2.3

截图中的Fuselage 4-p3选择了“保留闭合实体”。该选项跳过Surface重建，要求输入本身就是有效闭合实体；原始机身包含开放曲面，因此在重建开始前被拒绝。旧提示未说明恢复方法，选项名称也容易被理解为目标输出类型。

Surface模式下将“自动判断”明确标为“Surface 自动重建”，“保留闭合实体”标为“保留实体（不重建）”，并提供用途提示。选择保留实体时，若输入不是有效闭合体，立即恢复Surface重建并说明可直接导出。仅拒绝这个本就无法导出的选择；有效闭合实体仍可显式保留。

后端仍检查封闭性及自交，不将无效曲面伪称为有效实体。错误信息直接提示改回Surface重建；未勾选转换或选择原样保留的开放零件也会提示勾选及调整类型。误选被拒绝且有效选项没有改变时，已有转换缓存继续保留。

验证使用原始Fuselage 4-p3.stl、截图的0.25mm层高、0.42mm材料宽度和分件STL导出：先复现保留实体错误，再通过真实GUI选项恢复和导出，检查回读、文件校验值和两次导出只转换一次。实际测试结果及EXE校验值见test_evidence。

未修改逐层轮廓重建算法。切片仍须保持同一固定层高、原Z方向和Even-Odd。选择0.25mm重建时，目标切片也应使用0.25mm固定层高；不要沿用0.20mm模板中的层高。几何检查和导出成功不等于实际切片或实物打印验证。
