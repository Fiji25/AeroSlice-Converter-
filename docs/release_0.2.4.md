# AeroSlice Converter 0.2.4

使用原始Fuselage 3-p3.stl、0.20mm重建层高、0.45mm材料宽度复现：740个截面中，第641层（原坐标Z=62.397424mm）出现覆盖失败。合并后的折返短支线参与缓冲时，约0.056536mm原始线段落在0.008mm容差范围外。直接缓冲原始线段可以覆盖它；问题可缩减为三个二维线段的测试，不依赖整架航模数据。

修复只在原有覆盖检查失败时触发：定位未被覆盖的原始线段，以相同材料宽度生成线段缓冲，与已生成的材料区域求并集，随后用原来的0.008mm容差复查整个截面。不会删除已有材料，新增材料仅来自这些原始线段的名义宽度区域；复查仍失败就停止导出。正常截面沿用原路径，坐标结果不变。

报告记录修补层号、线段数量和补回材料面积，并在软件窗口显示修补统计。若仍发生截面覆盖错误，信息包含零件名、层号和Z坐标，便于定位。

回归覆盖短折返支线及平移变体、补回材料的范围、封闭挤出、正常截面完全不变，以及修补失败仍阻止导出。完整真实模型检查和最终EXE导入/转换/保存结果见随包test_evidence。

默认仍为逐层轮廓方案，连续曲面没有设为默认。层状外观及层间接触面保持原样；目标切片须保持原Z方向、相同固定层高和Even-Odd。保留已转换结果复用、直接保存到所选目录、无JSON旁文件、同名自动编号和误选保留实体保护。未进行实物打印验证。
